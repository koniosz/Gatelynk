Jak to działa?

  • Lokalna edycja (ta strona) — natychmiastowy zapis do Edge sqlite, VisionDetectService czyta dynamicznie przy każdym 60-sekundowym cyklu.
  • Cloud Integrator (gatelynk-web.fly.dev/integrator) — preferowane miejsce dla integratora wielobudynkowego. Cloud emit AI_ENGINE_CONFIG_UPDATE przez tunel → Edge nadpisuje swoją row.
  • Auto-migracja z env — Edge przy starcie sprawdza YOLO_URL env var. Jeśli sqlite jest pusty — kopiuje URL z env jako fallback. Po pierwszym świadomym zapisie status zmienia się na „Manual"/„Cloud".
  • Edge → Cloud sync — przy każdym reconnect tunela Edge raportuje swój aktualny config. Cloud upsert tylko gdy brak row — user-set z Cloud Integrator zawsze wygrywa.
